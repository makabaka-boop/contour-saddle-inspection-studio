# 等高线描线工作台

纯前端（不联网）的等高线描线工具：导入整数高程网格，按阈值 `levelTwice/2` 逐格描线，
以共享边标识把相邻格的线段拼接成**连续且确定**的开放折线 / 闭环，
SVG、折线表与下载 JSON 共用同一份计算结果。

技术栈：TypeScript + React + Vite，Vitest 测试，Docker Compose `web` 服务运行。

## 运行

```bash
# 本地
npm install
npm run dev        # http://localhost:5173

# Docker Compose（web 服务）
docker compose up --build   # http://localhost:5173

# 测试 / 覆盖率 / 构建
npm test
npm run coverage
npm run build
```

## 输入格式

```json
{
  "grid": [[0, 0], [0, 2]],
  "levelTwice": 1
}
```

- `grid`：2–60 行 × 2–60 列的整数矩阵，行宽一致；
- `levelTwice`：**奇数**整数，真实阈值 = `levelTwice/2`，因此不与任何整数顶点重合；
- 顶层只允许这两个字段——坏维度、非整数、缺字段或**额外字段**都会整份拒绝，
  界面保留上次有效网格并提示原因；编辑产生新的合法输入时立即撤销旧描线、整体替换。

## 描线规则

1. **交点**：对每条跨阈值网格边，以整数分数记录交点参数
   `t = (levelTwice − 2·h0) / (2·(h1 − h0))`，坐标全程为精确分数（`src/lib/fraction.ts`）。
2. **逐格线段**（`src/lib/contour.ts`）：每格 2 个交点连 1 段；四交点鞍格按四角均值裁决——
   - 均值 **高于** 阈值 → 连接两个**低角**周围的交点；
   - 均值 **低于** 阈值 → 连接两个**高角**周围的交点；
   - **恰等** → 固定连接**左上、右下角**周围的交点。
3. **拼接**：边以全局标识命名（`h:r:c` / `v:r:c` 及数字 id），相邻格共享边即共享交点；
   内部边度数恒为 2、边界边为 1，故每个连通分支必为开放折线或闭环。
4. **规范化**：开线从较小端点边标识起笔；闭环把最小边标识转到首位并取确定方向；
   折线列表按各自最小边标识升序排列——同一输入永远得到同一点序。

## 测试（Vitest）

`src/lib/contour.test.ts` 与 `src/lib/validate.test.ts` 覆盖：

- 鞍点三种裁决（均值高 / 低 / 恰等，含高角在另一对角线时的恰等对照）；
- 孤立高顶点生成的闭环及其规范点序、精确分数坐标；
- 单格角点触边界的开放折线；
- 相邻格共享交点（共享边只出现一次、三段拼成一条连续开线）；
- 输入校验：坏维度、非整数、偶数 levelTwice、额外 / 缺失字段、非 JSON。
